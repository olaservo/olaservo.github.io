# Changelog

Changes to the cards and the explorer, newest first. Dates are when the change was made in the source repo. The site is rebuilt from it afterwards.

## 2026-11-21

- [MCP Financial Services Interest Group](https://www.olahungerford.com/content-provenance/#mcp-fsig): the charter was amended on 2026-11-21. The group now collects problems and routes gaps to Working Groups, and does not sponsor SEPs. "Data lineage and citation" and "Data handling" stay in scope. - [C2PA content credentials in MCP _meta](https://www.olahungerford.com/content-provenance/#mcp-c2pa-in-meta): the 2026-09-25 closure links the maintainer comment that gives the reason.

## 2026-11-17

- `llms.txt` on olahungerford.com now lists the per-card files first and gives the size of `cards.md`, about 160 KB. In a test on 2026-11-17, five of six Claude Code sessions that started from `llms.txt` read `cards.md`, in two fetches each.
- The Worker's `robots.txt` no longer asks crawlers not to train on the cards. The cards are under CC BY 4.0, which allows any use with credit. It still says yes to search and to answer-time use. olahungerford.com's own `robots.txt` is unchanged.
- `llms.txt` on olahungerford.com now points at the prototype that serves one file per card, with its index, the reader skill and the plugin. It listed only `cards.md`, which holds every card in one file.
- [Agent Skills at-rest signing threads](https://www.olahungerford.com/content-provenance/#agent-skills-signing): discussion 651's mechanism, its example repository, and topics on covering the whole folder and on a removed credential. [Content Authenticity Initiative](https://www.olahungerford.com/content-provenance/#content-authenticity-initiative) notes the open c2pa-rs pull request the example depends on.
- The watch list gains Internet Exchange, a weekly newsletter on Internet governance and digital rights. It has no card.
- Cards can now say where an effort posts its news. `news` is its blog or announcements page and `feed` is the RSS, Atom or JSON feed. 42 cards have one or both, read on 2026-11-17. A new watch list, `watch.md` and `watch.json`, collects them for feed readers and scripts. It also lists sources with no card, kept in `watchlist.json`: The Scholarly Kitchen, MLCommons, IAB Tech Lab, the OpenTelemetry blog and the Bing Webmaster blog.
- The two skills and the MCP endpoint now install as one plugin in the [Agent Plugins](https://www.olahungerford.com/content-provenance/#agent-plugins) layout. The README has the steps for Codex and Claude Code.
- The cards are now under CC BY 4.0 and the code under MIT. `cards.json`, `updates.json`, `watch.json`, the plugin and the Worker's pages name the licence, and the README says which files each one covers.
- The plugin's version now changes with every publish, written as `2026.11.17+20`. A copy installed on 2026-11-17 kept its first set of cards after a second publish that day, and updates from this one on.
- Topic tags now have definitions and their own lists. `topics/skills.md` and `topics/discovery.md` list the cards with each tag, and the reader skill carries both. The explorer has a Topic filter row, and its front page defines the two topics. [Project NANDA](https://www.olahungerford.com/content-provenance/#project-nanda) gains the `topic/discovery` tag.
- Added [Google Scholar Mediated Reading](https://www.olahungerford.com/content-provenance/#google-scholar-mediated-reading): Google Scholar's Mediated Reading program and its MERU usage protocol, which [COUNTER Metrics](https://www.olahungerford.com/content-provenance/#counter) reports as `SYNDICATED:Google_MERU`. It notes that the AI metrics are optional and not audited.
- [Content Telemetry](https://www.olahungerford.com/content-provenance/#content-telemetry): new topics on coverage declarations and on reporting for an institution. v1.0 has no event for a refused retrieval.
