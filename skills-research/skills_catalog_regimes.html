Ola’s Agent Skills Research

a.k.a. Agent Skills are great, but how do they actually work?

How do harnesses bound their agent skills catalog?

Every host in this sample implements a baseline of:

  • name and description from the skill frontmatter gets injected into context
  • Most hosts below also include the file path for the SKILL.md in their catalog/manifest

Where they differ is what happens to the catalog itself as the number of installed skills grows.

sample and methodology

Findings are from reading source at the pinned revisions below and, where noted in the individual write-ups, running each host's own formatters and test suites against seeded skill directories.

bonus: what a constructed catalog actually looks like

Rendered out, the catalogs from these harnesses fell into two syntax families: XML elements per skill (pi, opencode, fast-agent, openclaw) or one plain line per skill (codex, goose, hermes). Verbatim examples from each host, and the degraded forms under budget pressure, are on a companion page.
