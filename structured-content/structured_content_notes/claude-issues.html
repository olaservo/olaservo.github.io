Claude clients: reported tool result handling

which mcp tool result fields are used and how (clients)

Claude Code, Claude Desktop, claude.ai, Cowork and Claude for Excel are closed source, so this note records what public issue reports say about content, structuredContent and audience. Nothing here was read from source. Each entry states what the reporter observed, the client and version they name, and the issue state, as of 2026-11-02. Issues are in anthropics/claude-code (CC) and anthropics/claude-ai-mcp (AI). Searches: gh search issues "structuredContent", "audience annotation" and "audience" "mcp" in both repositories, and gh issue view on each hit that concerns which field reaches the model, an MCP App, or audience.

Model path: structuredContent replaces content

  • AI #1201, open, 2026-10-29: in Claude Desktop 4.4 the model receives structuredContent in place of content for the Atlassian Rovo server, which shows an MCP App. The reporter says 3.6 sent content, and that ChatGPT and MCP Inspector send content. ochafik replied that _meta keeps data away from the model and quoted the specification’s SHOULD on the text mirror. The reporter replied that a widget does not render from _meta in MCP Inspector, and cited the MCP Apps specification draft and the ext-apps budget-allocator-server example.
  • CC #103396, open, 2026-10-19, labels bug, has repro, area:mcp: Claude Code sends only structuredContent when both fields are present. The Microsoft Fabric IQ server puts query rows in content[0].text and a citation card in structuredContent, and declares no outputSchema, so the model sees only the citation. A later comment reports the same result in claude.ai web chat through an org custom connector, retested 2026-10-29.
  • AI #1132, open, 2026-10-12: the same Fabric IQ connector returns citation-only results in Cowork and Claude Code and returns data in claude.ai chat with the unified experience off.
  • CC #79944, open, 2026-07-21: the text block is dropped when structuredContent is present. A comment reports it still reproduces on 2.1.304 (macOS, stdio), in the main session and in subagents.
  • CC #45575, closed not planned (stale) 2026-05-28: with both fields present, the terminal displays only structuredContent. The reporter says the model did receive the text at that time. #55677 (text dropped from the model) was closed as its duplicate by localden on 2026-05-06.
  • CC #64316, closed not planned (stale) 2026-07-03, and #59480, closed duplicate 2026-05-19: “structuredContent overrides content field, losing actual tool response”.
  • CC #54450, closed completed 2026-04-28: structuredContent displayed in place of content[0].text.
  • CC #54737, closed completed 2026-05-02: image blocks dropped when structuredContent is present.
  • CC #86032, open, labels reproduced: on an isError result structuredContent is dropped and the model gets only the text. bcherny reproduced it on v2.1.233 (macOS, claude -p, stdio).

MCP Apps: structuredContent missing from the view

  • AI #563, open, 2026-07-06: for local stdio servers in Claude Desktop, structuredContent and _meta.ui are present on upload and null when the conversation streams back, so widgets render empty. Cloud connectors are not affected.
  • AI #1158, open, 2026-10-19: after a chat reload, widgets get ui/notifications/tool-result without structuredContent.
  • CC #103809, open, 2026-10-20: in the Desktop Code tab, MCP App widgets receive no structuredContent, only the payload as JSON text.
  • AI #757, open, 2026-08-03: Claude for Excel on Mac returns empty data for structuredContent-only results unless content is also sent. The reporter says claude.ai handles them.

outputSchema

  • CC #90150, open, and #54197, closed not planned: requests to show outputSchema to the model.
  • CC #41361, closed completed: in 2.1.88 a result whose structuredContent failed the schema check was not shown.

audience

  • CC #72239, closed not planned 2026-09-15: a feature request to honour annotations.audience on tool-result blocks, so that ["user"]-only or ["assistant"]-only output can be collapsed in the TUI.
  • CC #18034, closed not planned 2026-02-26: a request to support the Annotations type (audience, priority, lastModified) on resources and content blocks. The reporter says Claude Code reads ToolAnnotations and not this type.

gh search issues "audience annotation" and "audience" "mcp" in anthropics/claude-ai-mcp returned no audience reports, only OAuth ones.
